Wallet

Built-in browser wallet for testnet3 legacy (m/n) addresses only. Imported keys are AES-256-GCM encrypted in localStorage and never sent to any server.

Search SupSpace

Search @handle, testnet3 address, #keyword, 64-char txid, or any text. The reader uses public p2fk.io APIs and flags unofficial handles to reduce identity theft.

Claim / edit profile

Profile editing only appears when the built-in wallet is unlocked. The editor is tied to the unlocked signature address. Handle availability must be checked before a new claim can be broadcast.

Unlock your built-in wallet to claim or edit the profile bound to its signature address.
