# SupSpace
Censorship free Sup!? social media 

Open `/home/runner/work/SupSpace/SupSpace/index.html` in a browser (or serve the folder locally) to use the single-file testnet3 P2FK app.

Current features:
- built-in encrypted testnet3 legacy wallet import/generation
- Sup!? profile claim/edit PRO transaction builder
- signed message composer with IPFS/on-chain attachments, hashtags, mentions, comments, and lightweight polls
- profile, message, and thread search via p2fk.io read APIs
